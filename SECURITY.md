# Security Policy

## Reporting a Vulnerability

If you find a security issue in Dowser, report it privately. Do not open a public issue.

- Use GitHub's "Report a vulnerability" button on the Security tab of this repository.
- Or email curtis.leggett.ltr@gmail.com with a description and reproduction steps.

## Response Timeline

- Acknowledgment within 7 days of report.
- Critical issues patched within 30 days.
- Reporter credited in the fix unless they prefer otherwise.

## Scope

**In scope:** vulnerabilities in the Dowser module code (Public/, Private/, Dowser.psm1, Dowser.psd1).

**Out of scope:** bugs in PowerShell itself, the .NET runtime, or the underlying operating system. Report those to their respective maintainers.
